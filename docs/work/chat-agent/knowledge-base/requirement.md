# knowledge-base 需求子集

> 从总需求提取，副本冻结。

## 范围内

- 用户上传文档（PDF/Word/Markdown）→ 系统解析、分块、向量化存储
- 用户提问 → RAG 检索相关知识片段 → 注入 LLM 上下文 → 生成带来源引用的回答
- 已上传文档管理（列表查看、删除）

## 范围外

- 结构化数据库查询（后续 MCP 场景）
- 图片/视频/音频文件
- 多租户隔离

## 验收标准

4. 上传一份 PDF → 系统解析并向量化存储 → 提示成功
5. 针对已上传文档内容提问 → 回复包含文档中相关信息并标注来源
6. 删除已上传文档 → 相关知识条目不可再被检索
