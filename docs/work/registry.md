## 维护规则

### 注册

- 阶段 plan 创建计划时 → 新增一行，状态 ⏳。类型：普通计划 `—`；总计划 `总计划`；子计划 `子计划 · <总计划目录>`
- 计划激活时 → 更新"当前激活"，状态改为 🔄

### 状态变更

- 计划暂停/阻塞时 → 状态改为 ⏸️ 或 🚧（若当前激活为该计划则清除"当前激活"）

### 注销

- 普通计划 / 子计划完成时 → 闭环审计通过后**删除此行**，清除"当前激活"
- 总计划完成时 → 所有子计划行已删除 + 集成审计通过后，删除总计划行，清除"当前激活"

### 恢复

- 人类说"继续" → AI 查"当前激活"确定要恢复的计划。若该行为子计划，同时读取总计划了解上下文
- 人类说关键词 → AI 搜"全部未完成"表找到对应目录

### 字段来源

registry 各列从 plan.md frontmatter 同步，不独立设置：

| registry 列 | frontmatter 字段 | 映射 |
|------------|-----------------|------|
| 状态 | `status` | 直接同步 |
| 自治 | `autonomy` | 直接同步 |
| 类型 | `type` | `standalone` → `—`；`master` → `总计划`；`sub` → `子计划 · <总计划目录>`（<总计划目录> 从总计划依赖图获取） |
| 计划目录 | — | 人工指定 |
| 分支 | `branch` | 直接同步 |
| 更新 | `updated` | 直接同步 |
