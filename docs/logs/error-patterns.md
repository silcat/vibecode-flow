# 错误模式追踪

## 用途

追踪跨会话反复出现的相同错误模式。当相同模式出现 ≥2 次时，触发阶段 ⑬ 技能提取。

## 规则

- 每次在日志或 bug 笔记中记录非琐碎错误时，检查此文件是否已有同类模式
- 同类模式第二次出现时，在此文件追加一条 + 在阶段 ⑬ 触发技能提取评估
- 保留历史记录，不删除旧条目
