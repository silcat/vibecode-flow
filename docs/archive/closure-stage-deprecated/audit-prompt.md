# 闭环审计提示词

在独立检查某个计划切片是否真正完成时使用此提示词。

所有创建的计划都需要闭环审计。

```text
阅读 `AGENTS.md`、`docs/index.md`、活跃需求/设计文档、活跃计划、qa-report.md、implement-report.md、code-audit.md、最新的相关日志条目以及活变更代码。

审计声称的实施是否真正闭环。

检查 `docs/baseline/context/project-context.md` 审查者可用性。冷重放不是第二个审查者，绝不批准保护区、未解决的产品风险或真源冲突。

聚焦于：
- 活行为是否匹配所述需求
- 计划的闭环关卡是否真正满足
- 证明是否存在于文件和验证结果中，而非仅聊天中
- 文档是否在受支持基线变更处已更新
- 任何剩余缺口是否仍在范围内
- 任务路由和记录的技能使用是否仍匹配交付的工作
- 自治级别或计划状态（frontmatter `status`）是否在没有持久证据的情况下被放宽
- 验证失败或未运行的命令是否被隐藏

首先返回发现，按严重程度排序。
如果闭环被阻塞，说 `需要修改` 并列出确切缺失的证明或变更。
如果切片可接受，说 `通过闭环审计` 并注明任何残余风险。
```
