# Bug 修复

## 文件角色

Bug 修复入口。路由触发条件：路由表命中 Bug。

## 首先阅读

| 如果你需要… | 先读 |
|-------------|------|
| 契约级 Bug 导向的主流程 | [main.md](main.md) |
| 日志回顾阶段 | [stages/log/README.md](stages/log/README.md) |

## 序列定义

| 阶段 | 条件 | 模块 |
|------|------|------|
| 诊断 | 始终 | 读相关代码，判断影响范围 |
| 分级 | 始终 | 判表层/契约 |
| bug分析 | 表层 | 判定是否需要根因分析（vc:debug）：明显问题（拼写错误、漏判空、硬编码错误等）不需根因分析；因果关系不清晰、涉及多模块交互、回归原因不明则需根因分析 |
| 直接修复 | 表层 + 不需根因分析 | 修复 → 验证 → log |
| vc:debug | 表层 + 需根因分析 | 根因分析 → TDD 修复 → 验证 → log |
| 契约路径 | 契约 | 进入 [main.md](main.md) |

## 表层路由

```
诊断 → 分级(表层) → bug分析
  ├─ 不需根因 → 直接修复 → 验证 → log
  └─ 需根因 → vc:debug → TDD 修复 → 验证 → log
```

## 属于这里的

- Bug 诊断与分级逻辑
- bug分析：判定是否需要根因分析
- 表层修复路径（直接修复 / vc:debug）

## 不属于这里的

- 契约级 Bug 的完整流程 → [main.md](main.md)
- 单个阶段的执行细节 → 各 stages/<stage>/README.md

## 更新原则

- 新增分级 → 在序列表中增加一行
- 分级条件变更 → 仅修改本文件条件列
