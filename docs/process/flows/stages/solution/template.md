# 方案文档模板（PRD）

## 命名

`docs/work/<branch>/solution.md`

## 模板

```markdown
# 方案文档 — <需求名>

## 决策上下文

需求：[链接 requirement.md]
摸底：[链接 investigate.md]

## 方案 A：<名称>

### 概述

[一句话描述核心思路]

### 涉及模块

| 模块 | 操作（新增/修改） | 说明 |
|------|-----------------|------|
| [模块名] | 修改 | [改什么] |

### 变更估算

新增文件约 N 个，修改文件约 N 个。

### 新增依赖

| 依赖 | 类型（库/服务/中间件） | 引入原因 |
|------|---------------------|---------|
| [名称] | 库 | [原因] |

### 架构影响

- 新服务：有/无
- DB 变更：有/无（[描述]）
- 通信方式变更：有/无（[描述]）

## 方案 B：<名称>

[同上结构]

## 方案 C：<名称>（如有）

[同上结构]

## 思维模型对比

| 维度 | 方案 A | 方案 B | [方案 C] |
|------|--------|--------|----------|
| **奥卡姆剃刀** — 假设/依赖/状态数 | | | |
| **逆向思维** — 怎样会失败？阻断点？ | | | |
| **多阶思维** — 后续连锁影响 | | | |
| **状态空间** — 可逆性、回滚代价 | | | |

## 推荐结论

**选定方案：** [方案名]

**核心理由：**
- [理由 1，对应思维模型中的关键维度]
- [理由 2]
- [理由 3]

**弃用方案及原因：**
- 方案 B：[核心否决原因]
- 方案 C：[核心否决原因]（如有）

## 风险与缓解

| 风险 | 影响 | 缓解措施 |
|------|------|---------|
| [风险描述] | [高/中/低] | [具体措施] |

## 结论

> ⏳ 待人类审查批准。
>
> 审查要点：
> - [ ] 选定方案的事实依据是否来自 investigate.md
> - [ ] 被拒方案的核心原因是否成立
> - [ ] 风险缓解措施是否可行
>
> 批准记录：[审查人] @ [日期] — [批准/需修改/否决]
```
