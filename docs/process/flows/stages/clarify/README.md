# 澄清模糊

## 文件角色

对需求和计划逐项追问澄清，对照已有文档和代码基线，在术语统一、边界明确后才进入下一阶段。使用 grill-with-docs 协议执行。

## 进入条件

discussion.md 已创建（来自 collect 阶段）。澄清是否存在模糊由 grill-with-docs 协议主动探测判定，不由进入条件预设"材料已完整→跳过"。

## 执行步骤

按 `docs/skills/engineering/grill-with-docs/SKILL.md` 执行逐个追问协议。

协议要点：
- 一次只问一个问题，每个问题附带 AI 推荐答案和理由
- 问题可先通过探索代码库回答则不问用户
- 四个检查维度轮询：术语挑战 → 精炼模糊语言 → 场景压测 → 代码交叉验证
- 无固定轮次上限，退出由 grill-with-docs 退出条件控制

## 产出物

| 产出 | 路径 |
|------|------|
| 讨论记录（问答 + 决议） | `docs/work/<branch>/discussion.md` |
| 术语决议 | `docs/baseline/context/glossary.md` |

## 完成证明

以下全部满足：

- 术语统一、无歧义
- 每个分歧点已有明确决议
- 阻塞性问题已解除或标记为待确认
- 讨论记录已写入 `docs/work/<branch>/discussion.md`
- 术语决议已写入 `docs/baseline/context/glossary.md`

## 完成报告

完成证明通过后，输出以下块：

`
**总结：** [1-2 句话总结本阶段产出]
**阻塞/顾虑：** [仅在有阻塞或顾虑时出现此字段]
**下一步：** 当前命中 [退出路由中的实际条件]，等待人类确认后进入 [对应去向]。
`

## 退出路由

完成证明通过后，等待人类确认才进入下一阶段。禁止自动推进。

| 条件 | 去向 |
|------|------|
| 澄清完成（术语统一、分歧决议已定） | → requirement |
| 仍有未决问题 | → 将未决问题写入 discussion.md，暂停等人类决策 |
