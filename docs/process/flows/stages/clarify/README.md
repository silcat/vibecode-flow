# 澄清模糊

## 文件角色

在输入材料不完整或矛盾时引导用户澄清模糊点，产出讨论记录。

## 进入条件

discussion.md 内容存在模糊点或矛盾。材料已完整则跳过本阶段。

## 执行步骤

按 `template.md` 引导用户逐项澄清。

约束：
- 一次只问一个问题
- 最多 2 轮
- 代码能回答的问题不向用户提问——先查代码

## 产出物

| 产出 | 路径 |
|------|------|
| 更新后的讨论记录 | `docs/work/<branch>/discussion.md` |

## 完成证明

讨论记录已追加澄清内容。直接在对话中确认即可。


## 完成报告

完成证明通过后，输出以下块：

`
**总结：** [1-2 句话总结本阶段产出]
**阻塞/顾虑：** [仅在有阻塞或顾虑时出现此字段]
**下一步：** 当前命中 [退出路由中的实际条件]，等待人类确认后进入 [对应去向]。
`

## 退出路由

完成证明通过后，等待人类确认才进入下一阶段。禁止自动推进。


| 条件 | 去向 |
|------|------|
| 澄清完成 | → requirement |
| 2 轮后仍未澄清 | → 将未决问题写入 discussion.md，暂停等人类决策 |
