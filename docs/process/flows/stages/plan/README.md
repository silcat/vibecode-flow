# 编写计划

## 文件角色

以 `type: standalone` 产出单计划文件，作为实施契约。进入条件：scope=单计划。

## 首先阅读

- [template.md](template.md) — 单计划模板与退出标准

## 执行

根据 requirement.md 和 audit 发现，按 [template.md](template.md) 填写计划。

## 产出

`docs/work/<工作目录>/plan.md`（`type: standalone`）

## 退出

→ plan-audit

## 回退

计划不可执行 → audit 或 requirement
