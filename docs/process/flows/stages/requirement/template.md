# 需求文件模板

## 命名

`docs/work/<branch>/requirement.md`

## 模板

```markdown
# [功能名] 需求

## 范围内
[本次要实现什么——用户能做什么、系统提供什么]

## 范围外
[明确不做什么——防止范围蔓延]

## 用户可见行为
- [用户操作 → 系统响应]
- [正常流程]
- [边界情况]

## 数据与规则
- [涉及的关键数据]
- [权限约束]
- [业务规则]

## 未决问题

## 验收标准

<!-- 每条必须可测试、可判定 pass/fail。计划测试矩阵行数 = 本条数 -->
1. [用户操作或条件 → 预期的系统响应或状态]
2. [边界情况 → 预期行为]
- [待确认项——标记为非阻塞才能进入下一阶段]
```
