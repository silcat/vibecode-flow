# 上下文索引

## 用途

`docs/baseline/context/` 存放 AI 代理在非平凡变更前必须阅读的简短强制性上下文。

此目录刻意保持精简。它存在的原因是：隐藏在 `docs/references/` 下的重要项目规则很容易被 AI 代理遗漏。

## 首先阅读

1. `project-context.md` — 项目标识、技术基线、验证命令、新鲜度当前值
2. `ai-autonomy-policy.md` — AI 何时可直接执行、何时必须停止，含文档新鲜度值域和维护规则
3. `codebase-map.md` — 代码仓库结构路由
4. `source-of-truth-and-precedence.md` — 真源优先级与冲突裁决
5. `conventions.md` — 项目级约定和规范路由表

## 属于这里的

- 每次 AI 会话都应用来定位方向的项目上下文
- AI 何时可以直接执行、需要计划、需要询问、需要调研或停止的自主权规则
- 避免重复发现结构的紧凑代码路由
- 真源与所有者文档优先级规则
- 不只是备查参考的项目级约定

## 不属于这里的

- 长篇设计文档
- 一次性分析
- 日常日志
- 执行计划
- 详细参考表

这些内容放到各自的所属目录中，仅在需要时从上下文链接过去。
