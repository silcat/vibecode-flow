# 需求缺口回顾提示词

在实施之后，当原始需求或原型未能完全覆盖真实交付需求时使用此提示词。

```text
阅读 `docs/work/<分支>/` 下的原始源文件、相关的 `docs/work/<分支>/`、最终需求文件、相关设计文档、实施计划和已落地的代码/日志。

分析为何原始需求基线未能完全覆盖最终实施现实。

聚焦于：
- 哪些源输入不完整
- 哪些假设隐式存在太久
- 原型保真度在哪里被误认为需求完整性
- PM 到实施的交接在哪里缺乏中间分析
- 什么应该更早进入需求合成或设计
- 应创建什么可复用技能、审计规则或工作流变更

产出回顾就绪的分析：
- 摘要
- 根因
- 错过的信号
- 过程改进
- 候选可复用技能或审计提示词
```
