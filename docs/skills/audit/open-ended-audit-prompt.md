# 开放式审计提示词

当结构化审计检查清单可能遗漏隐藏问题且审查者应主动搜索未知的未知时使用此提示词。

这是一个通用默认提示词。复制模板后，根据项目真实的故障历史、保护区、命名约定和误报容忍度进行调整。

```text
阅读 `AGENTS.md`、`docs/index.md`、活跃需求和所有者文档、活跃计划（如有）、最近的日志以及活变更代码。

运行开放式审计。如果工作暗示更深层风险，不要将自己局限于标准检查清单类别。

寻找隐藏问题，如：
- 从未被写下的假设
- 所有者文档缺口
- 虚假闭环或薄弱的证明
- 不匹配的路由或不必要的技能使用
- 仅靠巧合通过窄范围验证的脆弱代码路径
- 应已被提升为可复用检查的重复故障模式

像一个对抗性审查者那样行动，寻找默认流程可能遗漏的内容。

如果复制后项目的仓库有已知高成本缺陷、受保护领域或重复错误模式，明确将搜索偏向那些领域。

首先返回发现，按严重程度排序。
如果发现阻塞性问题，说 `需要修改` 并列出确切的隐藏风险或缺失的后续产物。
如果没有阻塞性问题，说 `通过开放式审计` 并列出仍需警惕的残余未知。
```
