# Bug 诊断提示词

当任务是 Bug 调查且失败尚未被明显的局部缺陷解释时使用此技能。

此技能用于在修复代码之前，通过可复现的反馈循环找到真正原因。

## 何时使用

- Bug 报告真实但失败层不清晰
- 症状可能是其他子系统的下游效应
- 问题是间歇性的、有状态的或时序敏感的
- 否则最可能的修复将只是猜测

## 何时不使用

- Bug 已缩小到清晰的一行缺陷
- 任务主要是功能工作，而非诊断

## 所需输入

- Bug 报告或观察到的症状
- 相关所有者文档
- 复现环境或最接近的可用夹具
- 当前验证命令

## 执行模式

1. 建立紧凑的反馈循环。
2. 复现失败并将其缩小到最小可靠案例。
3. 列出 3—5 个可证伪的假设。
4. 运行针对性实验快速排除假设。
5. 在修复前，尽可能添加或更新回归证明。
6. 落地最小的正确修复。
7. 重新运行验证并移除临时插桩。

## 输出

- 已确认的根因
- 被拒绝的假设及为何被拒绝
- 回归证明路径
- 残余风险或后续项
