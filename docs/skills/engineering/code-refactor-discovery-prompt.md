# 代码重构发现提示词

在变更结构之前使用此技能发现重构候选。

## 扫描维度

1. 过大文件
2. 重复或未收敛的逻辑
3. 隐藏的跨模块耦合
4. 一个模块中的混合职责
5. 脆弱的异步或生命周期模式
6. 层间的边界违规
7. 镜像实现而非契约的测试
8. 过时的兼容性残留
9. 变更区域周围的文档/代码偏移

## 审查规则

- 不要仅仅因为代码看起来很忙就提出重构
- 优先考虑将持续复发的结构风险
- 区隔行为保留重构和契约变更
- 命名具体收益：拆分、合并、隔离、统一或删除

## 预期输出

- 带证据的候选列表
- 每个候选为何重要
- 建议排序
- 当没有值得的重构时明确说明
