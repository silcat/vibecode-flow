# 代码重构提示词

当任务是改善结构而不改变受支持的行为时使用此技能。

## 护栏

- 无有意的行为变更
- 无隐藏的契约扩展
- 优先小型的、可审查的步骤
- 在每个结构切片后尽可能验证
- 保留现有公共名称，除非重命名是任务的一部分

## 允许的操作

- 拆分过大文件
- 提取有内聚性的辅助函数或模块
- 合并人工的包装层
- 移除死代码兼容路径
- 将重复逻辑标准化为一个契约

## 执行模式

1. 确认活基线和受保护行为
2. 定义确切的结构目标
3. 执行最小的安全结构切片
4. 运行聚焦验证
5. 当行为和结构开始同时变更时停止

## 预期输出

- 重构摘要
- 行为保持完整的证明
- 剩余结构债务（如有）
