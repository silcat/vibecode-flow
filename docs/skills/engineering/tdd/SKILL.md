# TDD

> 用途：阶段 ⑩ 实施循环的方法技能
> 触发：所有实施任务

## 铁律

生产代码必须先有失败测试。先写代码再补测试 → 删除代码，从 RED 重来。

## RED-GREEN-REFACTOR

**RED** — 为当前行为写一个最小失败测试
- 验证：运行测试，确认失败原因正确（功能缺失，非拼写/语法错误）
- 测试直接通过 → 测试写错了，修正

**GREEN** — 写刚好让测试通过的最少代码
- 不添加测试未覆盖的功能
- 不重构测试未涉及的代码
- 验证：运行该测试 + git diff 受影响测试，全绿、输出干净
- 测试未通过 → 修代码，不修测试
- 其他测试失败 → 立即修复

**REFACTOR** — 消除重复、改善命名、提取方法，保持全绿

循环直到任务所有行为覆盖。

## 红线（违反即回退）

- 生产代码先于测试写出
- 测试写完直接通过（从未失败过）
- "先实现再补测"
- "这次跳过 TDD"
