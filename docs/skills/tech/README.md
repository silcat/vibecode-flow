# 技术技能索引

## 用途

`docs/skills/tech/` 存放各技术栈的开箱即用技能指南。

每个技能回答 4 个问题：是什么、怎么接入、核心代码片段、已知坑。不写完整文档，只写下一个接手的人不用重新调研的内容。

## 目录结构

```
tech/
├── TEMPLATE.md          # 技能模板
├── <tech-name>/
│   ├── SKILL.md         # 开箱即用快速指南
│   └── refer/           # 学习资料（官方文档链接、教程、关键章节摘要）
```
